# Code-Flow | 유튜브 실시간 화면 OCR 추출 및 에디터 동기화 시스템

이 프로젝트는 유튜브 코딩 교육 동영상이 재생될 때, 현재 화면 상에 나타나는 소스코드를 무료 오픈소스 OCR 엔진을 통해 실시간으로 추출하여 웹상의 코드 에디터(CodeMirror)로 자동 주입하고 동기화해 주는 풀스택 시스템입니다.

---

## 🛠️ 사전 환경 구축 및 준비 사항

시스템 구동을 위해서는 파이썬 가상환경 구성 및 라이브러리 설치가 필요합니다. 본 프로젝트는 높은 정확도를 보장하는 네이버 Clova의 **EasyOCR** 엔진을 사용하며, 최초 실행 시 영어 및 한국어 문자 인식을 위한 가중치 모델 파일이 자동으로 로컬 디스크에 다운로드됩니다. (별도의 별도 OCR 엔진 설치 과정이 필요하지 않습니다.)

### 1. 파이썬 의존성 패키지 설치
터미널을 열고 프로젝트 루트 디렉토리에서 다음 패키지들을 설치해 주세요:

```bash
pip install fastapi uvicorn yt-dlp opencv-python easyocr
```

* **fastapi / uvicorn**: 비동기 백엔드 웹 서버 구동
* **yt-dlp**: 유튜브 비디오 재생 URL에서 다이렉트 미디어 스트림 주소 추출
* **opencv-python**: 비디오 스트림의 재생 프레임을 실시간으로 탐색하여 캡처
* **easyocr**: 네이버 Clova의 오픈소스 OCR 엔진을 기반으로 고정밀 텍스트 추출 기능 제공 (실행 시 PyTorch 등 의존 라이브러리가 함께 설치됩니다.)

---

### 2. 오픈소스 출처 표기 (공지)
* 이 프로그램은 네이버 Clova의 EasyOCR(Apache 2.0)을 사용했습니다.

## 🚀 구동 및 연동 방법

백엔드 서버와 프론트엔드 서버를 각각 띄운 후 연동하여 사용합니다.

### 1. 백엔드 API 서버 시작
프로젝트 루트 디렉토리에서 다음 uvicorn 명령어로 FastAPI 백엔드를 구동합니다.
기본 포트인 **8000**번 포트에서 가동됩니다.

```bash
uvicorn main:app --reload
```

서버 구동 즉시 로컬 디스크 상에 캐시 저장용 SQLite 데이터베이스(`ocr_cache.db`)가 자동 빌드됩니다.

### 2. 프론트엔드 웹 서버 구동
포트 충돌을 회피하기 위해 프론트엔드 포트는 **8080** 포트로 지정되어 있습니다.
PowerShell 터미널을 열고 다음 스크립트를 구동하여 웹 브라우저를 시작합니다:

```powershell
.\serve.ps1
```

이후 브라우저에서 `http://localhost:8080/index.html`로 접속하실 수 있습니다.

## 💡 주요 동작 사양 (동기화 조건)

- **자동 OCR 동기화**: '실시간 AI 자동 스캔' 토글이 **ON**인 상태로 영상을 재생하면, 초 단위로 백엔드에 캡처와 OCR 인식을 요청하여 에디터를 갱신합니다.
- **에디터 타이핑 보호**: 사용자가 에디터 영역을 클릭하여 타이핑이나 편집을 진행 중일 때(`editor.hasFocus() === true`)는 장면이 변하더라도 작성 중인 코드를 자동으로 덮어쓰지 않고 건너뜁니다.
- **타임라인 클릭 강제 갱신**: 하단의 '스마트 타임라인 리스트' 단원을 마우스로 직접 클릭하여 이동한 경우에는, 에디터의 포커스 상태를 무시하고 즉시 백엔드에 최신 프레임의 코드 텍스트를 요청해 강제로 에디터에 주입합니다.
- **SQLite 로컬 캐싱**: 한번 추출된 시간대의 프레임 OCR 데이터는 SQLite DB에 캐시 저장되어, 두 번째 탐색(Seek) 혹은 재학습 시 0.1초 이내로 대기 시간 없이 즉시 동기화가 이루어집니다.
