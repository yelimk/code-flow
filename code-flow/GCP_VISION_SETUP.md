# Google Cloud Vision API 연동 가이드 (GCP 설정)

이 가이드는 로컬 EasyOCR 대신 **Google Cloud Vision API**를 사용하기 위해 Google Cloud Platform(GCP)에서 프로젝트를 생성하고, 서비스 계정 키(JSON)를 발급받아 프로젝트에 연동하는 방법을 단계별로 설명합니다.

---

## 1단계: GCP 프로젝트 생성 및 API 활성화

1. **Google Cloud 콘솔 접속**: [Google Cloud Console](https://console.cloud.google.com/)에 구글 계정으로 로그인합니다.
2. **새 프로젝트 생성**:
   - 상단 메뉴의 프로젝트 선택 드롭다운을 클릭한 뒤, **[새 프로젝트]** (New Project)를 클릭합니다.
   - 프로젝트 이름(예: `code-flow-ocr`)을 입력하고 **[만들기]**를 클릭합니다.
3. **Cloud Vision API 활성화**:
   - 상단 검색창에 **"Cloud Vision API"**를 검색하고 클릭합니다.
   - **[사용]** (Enable) 버튼을 눌러 API를 활성화합니다.
   - *(최초 활성화 시 결제 계정 연동이 필요할 수 있으나, 비전 API는 매월 1,000건까지 완전 무료로 제공되므로 비용이 청구되지 않습니다.)*

---

## 2단계: 서비스 계정 및 인증 키(JSON) 발급

1. **서비스 계정 메뉴 이동**:
   - 왼쪽 사이드바 메뉴에서 **[IAM 및 관리자]** -> **[서비스 계정]** (Service Accounts) 메뉴로 이동합니다.
2. **서비스 계정 만들기**:
   - 상단의 **[서비스 계정 만들기]** (Create Service Account) 버튼을 클릭합니다.
   - 서비스 계정 이름(예: `vision-api-client`)을 입력하고 **[만들기 및 계속하기]**를 누릅니다.
   - **역할(Role) 선택**: 역할 선택 상자에서 **[Cloud Vision]** -> **[이동통신사/사용자]** 혹은 **[프로젝트]** -> **[뷰어]** (Viewer) 또는 **[소유자]** (Owner) 역할을 부여하고 **[완료]**를 누릅니다.
3. **비공개 키(JSON) 파일 생성**:
   - 생성된 서비스 계정의 이메일 주소를 클릭하여 상세 페이지로 들어갑니다.
   - 상단 탭에서 **[키]** (Keys) 탭을 클릭합니다.
   - **[키 추가]** -> **[새 키 만들기]** (Create new key)를 클릭합니다.
   - 키 유형으로 **[JSON]**을 선택하고 **[만들기]**를 누릅니다.
   - 다운로드된 JSON 파일은 보안상 매우 중요한 인증서입니다. 이 파일의 이름을 `gcp-key.json` 등으로 변경하여 **프로젝트 루트 디렉토리**(`c:\Users\82103\Desktop\ossw\codeflow\`)에 저장해 주세요.
   - > [!WARNING]
     > 이 키 파일은 개인 인증서이므로 GitHub 등 퍼블릭 저장소에 업로드(git push)되지 않도록 `.gitignore` 파일에 반드시 등록해야 합니다. (이미 본 프로젝트의 `.gitignore`에 등록되도록 연동 조치해 두었습니다.)
   - > [!TIP]
     > **트러블슈팅: "서비스 계정 키 생성 사용 중지됨" 오류 발생 시**
     > 구글 클라우드 보안 기본 설정 또는 조직 정책에 의해 키 생성이 차단된 경우, 아래 절차대로 정책을 일시적으로 허용(사용 중지)하여 키를 만들 수 있습니다.
     > 1. GCP 콘솔 상단 검색창에 **"조직 정책"** (Organization Policies)을 검색하고 클릭합니다.
     > 2. 리스트에서 **`iam.disableServiceAccountKeyCreation`** (서비스 계정 키 생성 중지) 항목을 찾아 클릭합니다.
     > 3. 상단의 **[정책 편집]** (Edit Policy) 버튼을 클릭합니다.
     > 4. 적용 대상 설정에서 **[맞춤]** (Customize)을 선택합니다.
     > 5. 정책 규칙에서 제약 조건을 **[사용 중지]** (Disable / Off)로 변경합니다. (제약 조건의 사용을 중지하면 키 생성이 허용됩니다.)
     > 6. **[저장]**을 누르고 1~2분 뒤 다시 서비스 계정 키 생성 단계를 시도합니다.

## 3단계: 환경 변수(`GOOGLE_APPLICATION_CREDENTIALS`) 설정

구글 클라우드 라이브러리는 실행 시 시스템 환경 변수에 정의된 `GOOGLE_APPLICATION_CREDENTIALS` 경로를 참조하여 자동으로 로그인 및 인증을 수행합니다.

### 방법 A: PowerShell 터미널에서 임시 적용 (서버 실행 전 매번 입력)
프로젝트 터미널(PowerShell) 창에서 아래 명령어를 실행하여 현재 터미널 세션에 키 경로를 임시 등록합니다.
```powershell
$env:GOOGLE_APPLICATION_CREDENTIALS="c:\Users\82103\Desktop\ossw\codeflow\gcp-key.json"
```

### 방법 B: Windows 시스템에 영구 등록 (권장)
매번 설정하지 않고 시스템에 영구 등록하려면 다음 단계를 따릅니다.
1. `Window 키 + R`을 누르고 `sysdm.cpl`을 입력하여 **시스템 속성**을 엽니다.
2. **[고급]** 탭 선택 후 하단의 **[환경 변수]** 버튼을 클릭합니다.
3. **[사용자 변수]** 또는 **[시스템 변수]** 영역에서 **[새로 만들기]**를 누릅니다.
   - **변수 이름**: `GOOGLE_APPLICATION_CREDENTIALS`
   - **변수 값**: `c:\Users\82103\Desktop\ossw\codeflow\gcp-key.json` (키가 위치한 실제 파일의 절대 경로)
4. 확인을 누른 후, **VS Code 등의 에디터와 터미널 창을 완전히 종료했다가 다시 시작**해야 변경된 환경 변수가 인식됩니다.

---

## 4단계: 백엔드 서버 재기동 및 확인
환경 변수 설정이 끝난 뒤, 프로젝트 루트 디렉토리에서 백엔드 서버를 구동합니다:
```bash
uvicorn main:app --reload
```
서버가 정상 구동되면, 실시간 OCR 요청이 발생할 때마다 발급받은 구글 키를 사용해 Google Cloud Vision API를 호출하며, 가상 터미널창에 호출 횟수가 실시간으로 정상 카운팅됩니다.
