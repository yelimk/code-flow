# [제품 요구사항 정의서 (PRD)] Code-Flow: AI YouTube Coding Assistant

## 1. 개요 및 5W1H 분석

본 문서는 유튜브의 코딩 강의 영상 내 소스코드를 실시간으로 인식 및 추출하여, 사용자의 웹 기반 에디터에 자동으로 동기화하고 실행할 수 있도록 지원하는 서비스 **'Code-Flow'**의 개발을 위한 요구사항 정의서(PRD)입니다.

| 항목 | 내용 |
| :--- | :--- |
| **Who (대상)** | 유튜브를 통해 코딩을 독학하는 개발 입문자, 학생 및 신기술을 빠르게 학습하고자 하는 현업 개발자 |
| **Why (목적)** | 영상 속 코드를 일일이 일시정지하고 직접 타이핑(타자 연습화)하는 번거로움을 줄이고, 에러 없는 실습 환경을 즉시 제공하여 학습 효율성을 극대화하기 위함 |
| **What (서비스)** | 유튜브 영상 스트리밍과 컴퓨터 비전(OCR/AI) 기반의 코드 추출 기술을 결합하여, 영상 속 코드를 우측 웹 에디터로 실시간 동기화 및 즉시 실행(Run)할 수 있는 통합 학습 플랫폼 |
| **When (시점)** | 사용자가 유튜브 코딩 강의 동영상을 시청하며 실습을 진행하는 모든 순간 |
| **Where (장소)** | 데스크톱 브라우저 환경 (Chrome, Edge 등 웹 기반 서비스 우선 출시) |
| **How (방법)** | 영상의 프레임을 실시간으로 분석하는 AI 스캐너가 코드 변화를 감지하고, 이를 에디터 영역에 삽입한 뒤, 백엔드 컨테이너 환경을 통해 원클릭으로 실행 결과를 반환 |

## 2. 기능 상세 정의 (Functional Requirements)

### F-01. 유튜브 플레이어 및 자동 스캔 모듈
* **요구사항 개요:** 유튜브 영상 링크를 연동하여 커스텀 플레이어로 재생하고, 영상 내 화이트보드나 화면 속 코드를 실시간 스캔합니다.
* **상세 사양:**
    * **유튜브 API 연동:** 표준 YouTube IFrame Player API를 활용하여 재생, 일시정지, 탐색(Seek) 기능 구현.
    * **자동 스캔(Auto Scan) 토글 스위치:**
        * `ON` 상태일 때: 영상 프레임 변화(5초 간격 또는 화면 전환 시)를 감지하여 OCR 파이프라인 가동.
        * `OFF` 상태일 때: 실시간 스캔을 중단하고 사용자가 현재 에디터 창을 독립적으로 수정 가능.
    * **코드 영역 바운딩 박스 추적:** 영상 내에서 소스코드 텍스트가 위치한 영역을 자동으로 탐지하여 컴퓨터 비전 모델의 입력값으로 전달.

### F-02. AI 기반 코드 에디터 동기화 모듈
* **요구사항 개요:** 스캔된 영상을 텍스트 코드로 변환하여 웹 에디터에 동기화하고, 수동 편집 및 저장 기능을 제공합니다.
* **상세 사양:**
    * **Vision-to-Code OCR Engine:** 영상 내 이미지(글자, 들여쓰기, 기호)를 정확한 소스코드로 복원. 파이썬의 경우 `Indent(들여쓰기)` 규칙 엄격 준수.
    * **실시간 코드 동기화:** 영상의 재생 타임라인에 맞추어 강사가 작성하는 코드가 우측 에디터에 실시간 레이어링(Append/Replace)됨.
    * **언어 선택 드롭다운:** `언어: Python ▽` 등 현재 영상의 대상 개발 언어를 선택 및 자동 감지하여 Syntax Highlighting 적용 (초기 MVP는 Python 필수 지원).
    * **실행 (Run) 버튼:** 작성되거나 스캔된 코드를 백엔드 샌드박스 환경으로 전송하여 즉시 실행 요청.
    * **ไฟล์로 저장 (`.py` 파일로 저장):** 에디터 내 소스코드를 로컬 PC에 물리 파일 형태로 다운로드 기능 제공.

### F-03. 스마트 타임라인 리스트 모듈
* **요구사항 개요:** 영상 내용 및 소스코드 분석을 통해 학습 챕터를 자동으로 분류하고 이동할 수 있는 탐색 가이드를 제공합니다.
* **상세 사양:**
    * **자동 챕터 생성:** 영상 메타데이터(유튜브 타임스탬프) 및 코드 내 주석/주요 함수 정의 시점(예: `def read_root():`)을 감지하여 타임라인 생성.
    * **예시 리스트 UI:**
        * `02:15 변수 선언`
        * `05:10 데이터 로드`
        * `08:45 서버 설정`
    * **인터랙티브 점프:** 특정 타임라인 아이템 클릭 시, 유튜브 비디오 플레이어의 재생 위치가 해당 시점으로 즉시 이동(Seek)하며 에디터 코드도 해당 시점의 상태로 동기화됨.

### F-04. 가상 터미널 및 실행 결과(Terminal) 모듈
* **요구사항 개요:** 에디터에서 작성된 코드가 실행되는 과정을 실시간으로 보여주는 개발자용 표준 출력 화면입니다.
* **상세 사양:**
    * **컨테이너 기반 샌드박스 실행:** 사용자가 `실행(Run)` 클릭 시, 서버 측의 격리된 Docker 컨테이너에서 해당 코드를 실행.
    * **로그 실시간 스트리밍:** 실행 프로세스의 `Stdout` 및 `Stderr`를 웹소켓(WebSocket)을 통해 프론트엔드 가상 터미널 화면에 출력.
    * **출력 예시:**
        ```bash
        > Running app...
        > Uicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
        ```
    * **에러 하이라이팅:** 코드 실행 실패 시, 터미널 로그 내 에러 라인과 원인을 붉은색 텍스트로 강조 표시하여 디버깅 직관성 제공.

## 3. UX Flow (사용자 경험 흐름)

### [Step 1: 강의 연동 및 탐색]
1. 사용자가 서비스 메인 화면 진입 후 학습하고자 하는 유튜브 코딩 강의 URL 입력.
2. 좌측 인터페이스에 유튜브 영상 로드 완료 및 하단에 `스마트 타임라인 리스트` 자동 생성 및 정렬.

### [Step 2: 자동 스캔 학습 활성화]
1. 사용자가 영상 하단의 `[자동 스캔: ON]` 토글을 활성화하고 영상을 재생.
2. 강사가 화이트보드 또는 코드 편집기 창에서 `import fastapi`, `app = FastAPI()` 등을 타이핑하기 시작.
3. 영상 재생 중 코드 변화가 감지되면, 우측 `코드 에디터` 영역에 해당 텍스트 코드가 실시간 레이어링되며 타이핑 효과 또는 실시간 라인 추가 발생.

### [Step 3: 코드 편집 및 검증]
1. 특정 섹션(예: `08:45 서버 설정`) 학습 중 사용자가 직접 코드를 수정해보고 싶을 때 영상을 일시정지함.
2. 우측 `코드 에디터` 창을 클릭하여 코드를 자유롭게 수정 (`return {"Hello": "World"}` -> `return {"Message": "Success"}`).
3. 상단의 `▶ 실행 (Run)` 버튼 클릭.

### [Step 4: 결과 확인 및 산출물 저장]
1. 우측 하단의 `4. 실행 결과 (Terminal)` 패널에 백엔드 실행 로그가 실시간 인터랙티브하게 표시됨.
2. 실행 결과가 만족스러울 경우, 에디터 상단의 `[.py 파일로 저장]` 버튼을 클릭하여 로컬 디렉토리에 소스코드 영구 저장.

## 4. 기술 스택 (Tech Stack)

### 4.1. Frontend
* **Framework:** React.js 또는 Next.js (컴포넌트 기반 UI 제어 및 SSR을 통한 초기 로딩 속도 최적화)
* **Editor Core:** Monaco Editor (VS Code 기반 라이브러리로, 강력한 Intellisense 및 Syntax Highlighting 지원)
* **Terminal Terminal Component:** Xterm.js (웹 환경에서 리눅스 스타일 가상 터미널 UI 완벽 구현)
* **State Management:** Zustand 또는 Redux Toolkit (비디오 재생 시점 - 에디터 코드 데이터 - 타임라인 상태 간 실시간 상태 동기화 관리)

### 4.2. Backend & AI Pipeline
* **API Gateway / Main Server:** FastAPI (Python 기반의 고성능 비동기 웹 프레임워크)
* **Computer Vision / OCR Engine:**
    * **1차 검증:** Google Cloud Vision API 또는 EasyOCR (영상 프레임 내 텍스트 바운딩 박스 추출)
    * **2차 보정:** LLM API (GPT-4o mini 등)를 이용한 코드 문맥 보정 파이프라인 (OCR 오류로 깨진 기호 `,`, `.`, `:`, `indent`를 프로그래밍 언어 문법에 맞게 자동 교정)
* **Code Execution Engine:** Docker Python Sandbox (사용자별 독립된 컨테이너 환경을 동적으로 할당하여 보안이 유지된 상태로 코드 실행)
* **Realtime Communication:** WebSocket (터미널 스트리밍 로그 및 코드 동기화 상태 전송용)

## 5. MVP 로드맵 (Minimum Viable Product Roadmap)

### **Phase 1: 인프라 구축 및 비전 엔진 검증 (1~4주차)**
* 유튜브 플레이어 및 Monaco Editor 기본 UI 레이아웃 구현.
* 영상 프레임 캡처 및 OCR을 통해 파이썬 코드를 텍스트로 추출하는 알고리즘 기본 검증.
* 단일 도커 컨테이너 내에서 코드를 실행하고 로그를 반환하는 백엔드 API 설계.

### **Phase 2: 핵심 연동 및 실시간 동기화 구현 (5~8주차) - [현재 이미지 스펙 단계]**
* `자동 스캔 ON/OFF` 스위치 연동 및 스캔 시점 자동 제어 최적화.
* 유튜브 플레이어 재생 시점과 우측 에디터 내 코드 라인의 실시간 매핑 레이어 개발.
* 타임라인 리스트 자동 추출 및 세그먼트 점프(Seek) 기능 안정화.
* Xterm.js를 활용한 터미널 출력 화면 고도화.

### **Phase 3: 사용자 편의성 및 최적화 (9~12주차)**
* 다양한 화면 해상도 대응을 위한 반응형 2단 레이아웃 분할 가변 그리드 적용.
* 파이썬 외에 JavaScript / HTML / CSS 등 멀티 언어 지원 확장.
* GitHub 연동 기능 추가 (작성한 코드를 로컬 다운로드뿐만 아니라 원클릭으로 개인 깃허브 레포지토리에 푸시).

## 6. 리스크 및 대응 전략 (Risk Management)

| 리스크 항목 | 발생 가능성 / 영향도 | 대응 및 해결 전략 (Mitigation Strategy) |
| :--- | :--- | :--- |
| **OCR 텍스트 인식 오류**<br>(특수문자 오인식으로 인한 코드 실행 에러) | **High / High** | OCR을 통해 추출된 원본 텍스트를 백엔드에서 경량 LLM(Code-LLaMA 또는 GPT 기반) 문법 검사기 피딩 단계를 거치게 하여 프로그래밍 언어 규격에 맞는 구문(Syntax)으로 1차 자동 보정 후 에디터에 삽입. |
| **악성 코드 실행 보안 위협**<br>(사용자가 터미널에 무한루프나 해킹 스크립트 실행) | **Medium / Critical** | 사용자가 실행하는 모든 코드는 호스트 OS와 격리된 **Docker Sandbox Container** 내부에서만 작동하도록 제약하고, 실행 시간 제한(Timeout 30초), 메모리 및 네트워크 아웃바운드 트래픽 사용량을 엄격히 제한(Quota 설정). |
| **스캐닝 비용 및 서버 부하**<br>(모든 프레임을 초당 분석할 시 API 비용 폭증) | **High / Medium** | 매 프레임을 분석하는 대신 **'화면 변경 감지 알고리즘(Pixel Difference)'**을 전처리 단에 도입하여 강사의 화면이 실제로 전환되거나 스크롤, 타이핑이 일어날 때만 OCR API를 호출하도록 설계하여 연산 비용을 80% 이상 절감. |
